# Hub de Exercícios - Lógica com JavaScript

Página centralizadora desenvolvida para reunir, organizar e facilitar o acesso a uma coleção de desafios práticos de programação web e lógica em JavaScript.

---

### Projetos Incluídos
- **Tabuada:** Calcula e exibe os múltiplos de 1 a 10 a partir de um número informado.
- **Verificador de Número:** Identifica se um valor numérico é positivo, negativo ou nulo.
- **Verificador de Número Primo:** Analisa e informa se o número inserido é primo.
- **Competição de Natação:** Ordena e define o pódio de três competidores com base em seus tempos.
- **Idade do Terceiro Filho:** Calcula a idade restante a partir da idade da mãe e dos dois primeiros filhos.

---

### Tecnologias Utilizadas
- **Estrutura e Estilo:** HTML5, CSS3
- **Lógica e Interatividade:** JavaScript
